# IN-HOUSE INTELLIGENCE — 社内情報特化型 AI 検索システム

本システムは、生成AI（GPT-4o mini）とRAG（検索拡張生成）技術を組み合わせ、社内に蓄積された膨大なドキュメントから「必要な情報」を瞬時に特定・要約するためのビジネスインテリジェンスツールです。

---

## 1. ビジネス仕様書（System Specifications）

### 1.1 システムの目的
社内の議事録、マニュアル、規程類、および指定のウェブサイト情報をAIが学習・参照することで、情報探索コストを大幅に削減し、意思決定の迅速化と知見の共有を促進します。

### 1.2 コアテクノロジー：RAG（Retrieval-Augmented Generation）
従来のAIとは異なり、社内の「最新かつ実在する文書」のみを根拠に回答を生成します。これにより、AI特有の「もっともらしい嘘（ハルシネーション）」を最小限に抑え、信頼性の高い情報提供を可能にしています。

### 1.3 主要機能
- **SEARCH DOCUMENTS（社内文書検索）**: 
  - 入力されたキーワードや文章に関連するドキュメントの「保存場所」と「ページ番号」を特定します。
  - 具体的な回答よりも「どの資料を見ればよいか」の特定に特化しています。
- **INQUIRY（社内問い合わせ）**:
  - 社内文書の内容をAIが読み解き、質問に対して具体的な回答を作成します。
  - プロンプトにより、詳細な解説や構造化された回答（箇条書き等）を出力します。

### 1.4 技術スタック
- **Frontend**: Streamlit
- **LLM**: OpenAI GPT-4o mini
- **Interaction**: LangChain (History-aware Retriever / Retrieval Chain)
- **Vector DB**: Chroma (ベクトル化された文書データの保存・検索)
- **Data Loaders**: PDF, Word, CSV, Text, WebBaseLoader

## 2. かんたん操作ガイド（User Guide）

中学生のみなさんでもわかるように、使いかたを3つのステップで紹介します！

### ステップ1：アプリを起動しよう
パソコンにある `run_app.bat` という名前のファイルをダブルクリックするだけです。
黒い画面が出てきたあとに、自動でブラウザ（インターネットの画面）が立ち上がります。

### ステップ2：やりたいことを選ぼう
画面の左側（サイドバー）にあるボタンで、どちらのモードを使うか選びます。
- **「SEARCH DOCUMENTS」**: 「あの資料、どこにあったっけ？」とファイルを探したいとき。
- **「INQUIRY」**: 「これについて教えて！」とAIに質問して答えがほしいとき。

### ステップ3：メッセージを送ろう
画面の下にある入力欄に、聞きたいことを書いてエンターキー（または送信ボタン）を押すだけです。
- **コツ**: 「昨日の会議について」よりも「2026年3月30日の新プロジェクト会議について」のように、**具体的**に書くとAIがもっと正確に答えてくれます！

## 3. セットアップと起動（for Admin）

### 準備するもの
1. Python 3.10 以上がインストールされていること。
2. `.env` ファイルに `OPENAI_API_KEY` が設定されていること。

### セットアップ手順（初回のみ）
バッチファイルを動かす前に、一度だけ以下の操作を行ってください。
1. **ターミナルを開く**: このフォルダ(`company_inner_search_app`)を右クリックして「ターミナルで開く」を選択。
2. **有効化**: `env\Scripts\activate.bat` と入力してエンター。
3. **インストール**: `pip install -r requirements.txt` と入力してエンター。

これが完了すれば、次からは **`run_app.bat` をダブルクリックするだけ** で起動します。

### データの更新方法
`data` フォルダの中に、PDFやWordファイルを自由にコピーしてください。
アプリを再起動すると、AIが新しいファイルを自動的に読み込みます。

## 4. セキュリティ・品質の配慮
- **履歴管理**: 過去10往復の会話のみを記憶することで、動作の軽量化とプライバシーのバランスを保っています。
- **エラー処理**: ファイルが壊れていたり、ネットワークがつながらなくても、システム全体が止まらないように設計されています。
